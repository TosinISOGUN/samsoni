# SAMSONI Water — Pure Hydration for Lagos

SAMSONI Water is a premium, NAFDAC-certified table water brand dedicated to delivering high-quality hydration solutions to homes, offices, and events across Lagos, Nigeria. This website is designed to provide a seamless, mobile-first ordering experience with direct WhatsApp integration.

## 🚀 Key Features

- **Premium Modern Design**: A high-end visual identity using **Bricolage Grotesque** and **Plus Jakarta Sans** typography.
- **WhatsApp Integration**: A streamlined "Quick Order" system that connects customers directly to the sales team on WhatsApp.
- **Mobile-First Navigation**: Features a sophisticated slide-out sidebar and full-screen overlay optimizations for a native app-like experience.
- **NAFDAC Compliance**: Proudly displays NAFDAC Registration Number (**E1-6702L**) to ensure customer trust and transparency.
- **Advanced SEO & Sitemapping**: Fully optimized with dynamic meta tags, automated sitemaps, and robots.txt for maximum search engine visibility.
- **Responsive Layout**: Towering hero sections (110vh) and optimized spacing to prevent layout issues on dynamic mobile browser bars.

## 🛠️ Tech Stack

- **Frontend**: React (v18+) with Vite
- **Styling**: Tailwind CSS for high-performance, responsive styling
- **Icons**: Lucide React
- **UI Components**: Shadcn/UI (Radix UI primitives)
- **SEO**: React Helmet Async
- **Routing**: React Router DOM (v6+)
- **Build & Deployment**: Vercel

## 📦 Local Development

1. **Clone the repository**:
   ```bash
   git clone https://github.com/TosinISOGUN/samsoni.git
   cd samsoni
   ```

2. **Install dependencies**:
   ```bash
   npm install --legacy-peer-deps
   ```
   *(Note: `--legacy-peer-deps` is required for Vite 8 / SWC plugin compatibility)*

3. **Run the development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```
